# بوت تيليجرام لتحميل الفيديوهات والستوريات 🎬

بوت جاهز للعمل يحمّل الفيديوهات والصور والستوريات من مواقع التواصل الاجتماعي،
ويعيد إرسالها للمستخدم بأفضل جودة، **وبدون علامة مائية قدر الإمكان**، مع
**حذف تلقائي من السحابة بعد 3 ساعات**.

---

## ✨ الميزات

| الميزة | التفاصيل |
|---|---|
| منصات مدعومة | **تيك توك، إنستغرام (منشورات/ريلز/ستوريات)، فيسبوك** — مُقصورة على هذه المنصات للسرعة، ويمكن توسيعها عبر `ALLOWED_PLATFORMS` |
| بدون علامة مائية | تيك توك: يختار البوت نسخة `play` النظيفة ويرفض نسخة `download` المدمجة بالعلامة، مع **مصدر بديل تلقائي** إذا حجب الموقع الخادم. باقي المنصات لا تضيف علامة من الأساس |
| إزالة اسم المستخدم من الفيديو | يفحص البوت **كامل الإطار** عبر OCR في عدة إطارات، يطابق النص مع اسم صاحب المحتوى (مع تحمّل أخطاء القراءة)، ويزيله بـ `delogo`. وإذا كان التشويه محتملًا يسألك عن **نص بديل** يضعه في نفس المكان بنفس الحجم واللون وأقرب خط |
| وصول مضمون للمستخدم | إن كان الفيديو أكبر من 50MB: **ضغط تلقائي** أولًا، وإن لم يكفِ **تقسيم إلى أجزاء** وإرسالها كلها |
| حذف تلقائي | مهمة دورية تحذف كل ملف بعد **3 ساعات** من تحميله (قابلة للتعديل) |
| ستوريات متعددة | يدعم أكثر من ملف في الرابط الواحد (كاروسيل/ستوريات) |
| مقاومة الأخطاء | إعادة محاولة للتحميل والإرسال، معالجة حدود تيليجرام، رسائل خطأ عربية واضحة |
| وضعان للتشغيل | Polling محليًا، وWebhook تلقائيًا على Render |

## 🚀 التشغيل المحلي (الآن)

المتطلبات: **Python 3.11+** فقط. ffmpeg مضمّن تلقائيًا عبر حزمة
`imageio-ffmpeg`، ويمكن أيضًا تثبيت نسخة النظام إن أردت.

```powershell
# 1) تثبيت المكتبات
pip install -r requirements.txt

# 2) التشغيل
python -m bot
```

أو انقر نقرًا مزدوجًا على `run.bat` (يعيد التشغيل تلقائيًا عند أي توقف).

> ملف `.env` جاهز بالفعل ويحتوي توكن البوت. أرسل `/id` للبوت لمعرفة معرّفك،
> ثم ضعه في `ADMIN_IDS` لتفعيل أوامر المشرف (`/clean` و`/status` التفصيلي).

## ☁️ النشر على Render

الحساب والمفتاح صالحان (تحقّقت منهما). لا توجد خدمة منشورة بعد، والطريقة الأسهل:

1. ارفع المشروع إلى مستودع GitHub (خاص أو عام).
2. من لوحة Render: **New → Blueprint** واختر المستودع.
3. سيكتشف Render ملف `render.yaml` تلقائيًا.
4. أدخل قيمة `BOT_TOKEN` عند الطلب (وارفع `ADMIN_IDS` إن أردت).
5. اضغط **Apply**.

سيتحوّل البوت تلقائيًا إلى **Webhook** لأن Render يوفّر `RENDER_EXTERNAL_URL`.

### ملاحظات Render المجاني
- الذاكرة 512MB ووحدة معالجة ضعيفة: الضغط قد يكون بطيئًا، لذلك الافتراضي
  `MAX_CONCURRENT_DOWNLOADS=1` والتقسيم بدون إعادة ترميز (سريع).
- الخدمة تنام بعد 15 دقيقة بلا طلبات، وتستيقظ عند أول رسالة (قد يتأخر الرد
  نصف دقيقة في أول مرة). رسائل تيليجرام محفوظة ولا تُفقد.
- قرص Render المجاني مؤقت: الملفات تختفي عند إعادة النشر، وهذا متوافق مع
  سياسة الحذف بعد 3 ساعات.

## 🍪 كوكيز إنستغرام والستوريات الخاصة

ستوريات إنستغرام والحسابات الخاصة تتطلب تسجيل دخول. صدّر كوكيز المتصفح
بصيغة Netscape (`cookies.txt`) ثم اختر إحدى الطرق:

**الأسهل:** أرسل ملف `cookies.txt` كمستند إلى البوت من حساب المشرف
(بعد ضبط `ADMIN_IDS`)، وسيُحدَّث فورًا دون إعادة تشغيل.

أو عبر الإعدادات:

```env
COOKIES_FILE=cookies.txt
# أو للسحابة (Base64 للمحتوى):
COOKIES_B64=...
```

بدون كوكيز سيعمل المحتوى العام فقط. تيك توك قد يحجب بعض عناوين IP
(خطأ 403)؛ استخدم `PROXY_URL` عند الحاجة.

## 🧼 إزالة العلامة المائية واسم المستخدم

- **تيك توك**: يُحمَّل تلقائيًا من نسخة `play` غير المعلّمة. وإذا حجب تيك توك
  عنوان IP الخاص بالخادم (خطأ 403) يتحوّل البوت تلقائيًا إلى مصدر بديل
  يعيد نفس النسخة النظيفة.
- **إنستغرام / فيسبوك / إكس / يوتيوب / ريديت / بينترست**: لا تضع علامة مائية
  على الفيديو الأصلي.
- **اسم المستخدم المطبوع داخل الفيديو**: يفحص البوت **كامل الإطار** عبر OCR
  في حتى 10 إطارات (تشمل بداية الفيديو ونهايته)، ثم يجرّب **فحصًا مكبّرًا
  لأربع زوايا** إن لم يجد الاسم. يطابق أي نص مع اسم صاحب المحتوى
  (الهاندل في الرابط أو اسم القناة) مع تحمّل أخطاء القراءة (مطابقة تقريبية).
- **إذا كان التشويه محتملًا** (نص كبير أو في وسط الصورة أو خلفية معقّدة):
  يُرسل البوت الفيديو الأصلي ثم يسألك:
  - أرسل **النص البديل** (مثل `@myaccount`) وسيضعه مكان الاسم **بنفس الحجم
    واللون وأقرب خط متاح**.
  - أو أرسل **«إزالة»** لإزالة الاسم فقط دون بديل.
  - أو **«تخطي»** لإبقاء الفيديو كما هو.
- **إذا لم يتعرّف على الاسم تلقائيًا**: أرسل `/fix` ثم أرسل النص كما يظهر
  بالضبط، أو `القديم => الجديد` للاستبدال.
- **سناب شات**: بعض الفلاتر والملصقات تكون **مدمجة داخل الفيديو** ولا يمكن
  إزالتها دون تشويه الصورة.

> إزالة الاسم تعمل على الفيديو حتى مدة `USERNAME_MAX_SECONDS` (10 دقائق
> افتراضيًا) لأنها تعيد ترميز الفيديو كاملًا. للمقاطع الأطول يُرسل الفيديو
> الأصلي مع إبقاء العلامة، حفاظًا على سرعة الوصول.
>
> تعتمد الميزة على حزمة `rapidocr-onnxruntime` (مثبّتة في `requirements.txt`).
> إذا تعذّر تثبيتها أو تحميلها، يكمل البوت عمله ويرسل الفيديو كما هو دون توقف.
> عند الحاجة لإزالة أي يوزر مكتوب بصيغة `@name` وليس فقط اسم صاحب المحتوى،
> فعّل `USERNAME_ANY_MENTION=true`.

## ⚙️ الإعدادات (ملف `.env`)

| المتغير | الافتراضي | الوظيفة |
|---|---|---|
| `BOT_TOKEN` | — | توكن البوت |
| `ADMIN_IDS` | فارغ | معرّفات المشرفين مفصولة بفاصلة |
| `STORAGE_DIR` | `storage` | مجلد التخزين المؤقت |
| `RETENTION_HOURS` | `3` | مدة بقاء الملف قبل الحذف |
| `CLEANUP_INTERVAL_SECONDS` | `300` | تكرار فحص الحذف |
| `MAX_UPLOAD_MB` | `49` | الحد الآمن لتيليجرام |
| `MAX_CONCURRENT_DOWNLOADS` | `2` | عدد التحميلات المتزامنة |
| `MAX_URLS_PER_MESSAGE` | `5` | أقصى عدد روابط في الرسالة |
| `USER_COOLDOWN_SECONDS` | `5` | منع التكرار السريع |
| `MAX_VIDEO_DURATION_SECONDS` | `3600` | أقصى مدة فيديو |
| `REMOVE_USERNAME` | `true` | تفعيل إزالة اسم المستخدم المطبوع |
| `ALLOWED_PLATFORMS` | `tiktok,instagram,facebook` | المنصات المفعّلة (فارغ = الكل) |
| `USERNAME_OCR_FRAMES` | `10` | عدد الإطارات المفحوصة بالـ OCR |
| `USERNAME_MAX_SECONDS` | `600` | أقصى مدة فيديو تُعالج لإزالة الاسم |
| `USERNAME_OCR_WIDTH` | `1280` | عرض الإطار في OCR (أعلى = أدق وأبطأ) |
| `USERNAME_OCR_MIN_SCORE` | `0.25` | أقل ثقة مقبولة من OCR |
| `USERNAME_RISK_THRESHOLD` | `0.45` | عند تجاوزها يُسأل المستخدم عن نص بديل |
| `USERNAME_OFFER_MANUAL` | `true` | اقتراح `/fix` عند عدم العثور على الاسم |
| `USERNAME_FONT_FILE` | — | خط بديل اختياري للنص المستبدل |
| `USERNAME_ANY_MENTION` | `false` | إزالة أي نص يبدأ بـ `@` وليس فقط اسم صاحب المحتوى |
| `COOKIES_FILE` / `COOKIES_B64` | — | كوكيز المواقع |
| `PROXY_URL` | — | بروكسي اختياري |

## 🤖 أوامر البوت

| الأمر | الوظيفة |
|---|---|
| `/start` | ترحيب وشرح |
| `/help` | طريقة الاستخدام |
| `/id` | معرّفك ومعرّف المحادثة |
| `/status` | حالة الخدمة (وللمشرف: إحصائيات التخزين) |
| `/clean` | للمشرف: حذف الملفات المنتهية |
| `/clean all` | للمشرف: حذف كل الملفات فورًا |
| `/cookies` | حالة الكوكيز (والمشرف يحدّثها بإرسال ملف) |
| `/fix` | إزالة/استبدال اسم لم يتعرّف عليه البوت يدويًا |

## 🧪 الاختبار السريع

```powershell
python -m compileall bot          # فحص الصياغة
python -m bot                     # تشغيل
```

ثم أرسل للبوت رابطًا مثل منشور تيك توك عام، وراقب السجلات.

## 🔐 تنبيه أمني

التوكن ومفتاح Render كانا مكتوبين نصًا صريحًا في `بيانات.txt`. بعد التأكد من
عمل كل شيء، يُفضّل:

1. إعادة توليد توكن البوت من `@BotFather` → `/revoke`.
2. إعادة توليد مفتاح Render وحذف المفتاح القديم.
3. عدم رفع `.env` أو `cookies.txt` إلى Git (مستثناة في `.gitignore`).
